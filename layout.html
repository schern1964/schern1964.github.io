Поток

Ппоток - порядок отображения элементов на веб-странице. Сам поток задаётся структурой HTML-кода и элементы на веб-странице по умолчанию отображаются в том же порядке, как они идут в коде HTML.

Флексбоксы

Flexbox (Flexible Box Layout) — это модуль CSS, предназначенный для создания гибких и адаптивных макетов.

CSS Grid

CSS Grid позволяет создавать сложные макеты, адаптирующиеся к размерам экрана. Его особенность в том, что сетка строк и колонок полностью задаётся в CSS и нам не нужно добавлять дополнительные HTML-элементы.
